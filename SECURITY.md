# Security Policy

Berack is early-stage software. Please do not post sensitive security reports in public issues.

## Reporting a Vulnerability

Open a private security advisory on GitHub, or contact the maintainer directly if private advisories are not available yet.

Please include:

- A clear description of the issue.
- Steps to reproduce.
- Impact and affected versions, if known.
- Any suggested mitigation.

## Sensitive Data

Never commit `.env`, SQLite databases, generated API keys, logs, `vendor/`, or `node_modules/`.
